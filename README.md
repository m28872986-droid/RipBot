# بوت الإدارة والحماية

## التشغيل
1. ثبّت Node.js 20 أو أحدث.
2. انسخ `.env.example` إلى ملف باسم `.env`.
3. ضع توكن البوت في `DISCORD_TOKEN` داخل `.env` — لا ترسله لأي شخص.
4. نفّذ `npm install` ثم `npm start`.

## إعداد Discord Developer Portal
فعّل Privileged Gateway Intents:
- Server Members Intent
- Message Content Intent

امنح البوت الصلاحيات اللازمة للإدارة والحماية، ويفضل عدم إعطائه Administrator إلا إذا كنت تثق بالبيئة. يجب أن تكون رتبة البوت أعلى من الرتب التي سيديرها.

## الأوامر
كل أمر يعمل بثلاث صيغ: `!ban` أو `ban` أو `باند` (حسب الأمر).
- `!setup` أو `إعداد` — اختر رتبة الإدارة وروم السجلات من القوائم.
- `!help` أو `مساعدة` — شرح الأوامر والأمثلة.
- `باند @عضو 1d السبب` — حظر مؤقت يومًا ثم فك الحظر تلقائيًا.
- `كيك @عضو السبب`
- `تايم @عضو 10m السبب`
- `تحذير @عضو السبب`
- `مسح 20`
- `ميوت @عضو 10m` — الميوت هنا Timeout.
- `فك ميوت @عضو`
- `قفل` / `فتح` — في الروم الحالي.
- `حماية تشغيل` / `حماية إيقاف`
- `لوق` — يعرض روم السجلات الحالي.

ملاحظة: الأوامر بدون `!` لا تُنفّذ إلا إذا بدأت الرسالة بأحد أسماء الأوامر المعروفة، لتقليل التعارض مع المحادثات العادية.
