# YovnBot — النسخة المدمجة

## التشغيل
- Node.js 20.18 أو أحدث (يفضل Node 22).
- Build command: `npm install`
- Start command: `npm start`
- أضف `DISCORD_TOKEN` في متغيرات الاستضافة.
- فعّل Message Content Intent وServer Members Intent من Discord Developer Portal.
- أعطِ البوت صلاحيات قراءة/إرسال الرسائل، إدارة الرتب، إدارة الرسائل في شات الرومات الصوتية، والاتصال والتحدث في روم الموسيقى.
- انسخ `config.example.json` إلى `data/config.json` وعدّل الإعدادات. لا تستبدل ملف `data/config.json` أو `data/privateRoles.json` الموجودين لديك إذا كانا يحتويان بيانات سابقة.

## الأوامر القديمة المحفوظة
- `!help` أو `!مساعدة`
- `!setup` أو `!اعداد`
- `!تيك`
- `!فيلنق` أو `!feeling` (متاح للجميع)
- `!زاجل` أو `!zajel` (متاح للجميع)
- `!شروط`
- `!رتب`
- `!addrole @role السعر`
- `!removerole @role`
- `!addrd كلمة | الرد` أو `!اضفرد كلمة | الرد`
- `!delrd كلمة` أو `!حذفرد كلمة`
- `!editrd كلمة | الرد الجديد` أو `!تعديلرد كلمة | الرد الجديد`
- `!listrd` أو `!الردود`

## الرتب الخاصة
- `!role` — إنشاء رتبة خاصة، مع تطبيق أيقونة الرتبة إذا كان السيرفر يدعمها.
- `!myrole` — لوحة إدارة الرتبة: أعضاء، اسم، لون، نقل الملكية، أيقونة، ونائب.
- `!تجديد @الرتبة 6 اسبوع` — تجديد الرتبة وإرجاعها لحامليها السابقين.
- يتم فحص انتهاء الرتب تلقائيًا كل دقيقة، وإزالة الرتبة من حامليها عند انتهاء مدتها دون حذف الرتبة من السيرفر.

## الميزات المضافة
- `!خط` — يرسل صورة الخط داخل الرسالة كصورة ظاهرة (Embed Image) مع إرفاق الصورة نفسها. يفضّل وضع الصورة الأصلية في `assets/font-image.png` حتى لا يتأثر الأمر بانتهاء صلاحية رابط Discord؛ إذا لم يوجد الملف يستخدم `fontImageUrl` كحل احتياطي.
- `!قص` مع إرفاق صورة، أو `!قص رابط_الصورة` — إزالة خلفية الصورة. يتطلب متغير `REMOVE_BG_API_KEY` من خدمة Remove.bg.
- `!addreact كلمة | 😀` — إضافة رياكشن تلقائي للكلمة (Administrator فقط).
- `!delreact كلمة` — حذف رياكشن تلقائي.
- `!listreact` — عرض الرياكشنات التلقائية.
- تنظيف شات الرومات الصوتية والرومات المسرحية كل 5 دقائق. يحذف الرسائل الأحدث من 13 يومًا فقط لتجنب حد Discord الخاص بالحذف الجماعي.
- الموسيقى في الروم المحدد في `musicVoiceChannelId`:
  - `ش` أو `شغل` أو `play` مع اسم/رابط.
  - `وقف` أو `stop`.
  - `س` أو `سكب` أو `skip`.
  - `ص 1-150` أو `v 1-150`.

## إعدادات مهمة
- `assets/font-image.png`: المكان المفضل للصورة الأصلية؛ أضف الملف بهذا الاسم داخل مجلد `assets` في المشروع. إذا لم يكن موجودًا، يستخدم البوت `fontImageUrl` أو `FONT_IMAGE_URL` كرابط احتياطي، وقد تنتهي صلاحية روابط Discord الموقّعة.
- `autoReactions`: قاموس الكلمات والإيموجيات، وتدار أوامره من داخل Discord.
- `REMOVE_BG_API_KEY`: مطلوب لميزة `!قص` فقط؛ لا تضع المفتاح داخل ملفات المشروع أو ترفعه إلى GitHub.
- `musicVoiceChannelId`: معرّف روم الموسيقى.

## ملاحظات حماية البيانات
هذه الحزمة لا تحتوي على توكن البوت أو ملف إعداداتك الفعلي أو سجل رتبك الخاصة؛ الملفات الأصلية الأربعة التي وصلتني لم تتضمن `data/config.json` أو `data/privateRoles.json`. سيُنشئ البوت إعدادات افتراضية إذا لم تكن موجودة، لذلك احتفظ بنسخة من بيانات الاستضافة الحالية قبل استبدال الملفات.
