# YovnBot

## التشغيل على Render
- Build Command: `npm install`
- Start Command: `npm start`
- أضف `DISCORD_TOKEN` في Environment Variables.
- استخدم Node.js 20.18 أو أحدث (ويُفضّل Node.js 22).
- فعّل Message Content Intent وServer Members Intent عند الحاجة.
- أعطِ البوت صلاحيات View Channel وConnect وSpeak في روم الصوت.
- فعّل Message Content Intent من Developer Portal.
- التشغيل من الاسم يعتمد على المصادر/المستخرجات المتاحة؛ روابط Spotify قد تُستخدم للبحث ولا تعني بث Spotify نفسه.

## روم الموسيقى
روم الصوت المعتمد حاليًا: `1564997033025081445`
يمكن تغييره من `musicVoiceChannelId` داخل `data/config.json`.

## أوامر الموسيقى (بدون برفكس)
- `ش <اسم الأغنية أو الرابط>` أو `شغل <اسم الأغنية أو الرابط>` أو `play <اسم الأغنية أو الرابط>`
- `وقف` أو `stop`
- `س` أو `سكب` أو `skip`
- `ص 1-150` أو `v 1-150`

## الأوامر القديمة
- `!help` أو `!مساعدة`
- `!setup` أو `!اعداد`
- `!تيك`
- `!فيلنق` أو `!feeling`
- `!زاجل` أو `!zajel`
- `!شروط`
- `!رتب`
- `!addrole @role السعر`
- `!removerole @role`
- `!addrd كلمة | الرد` أو `!اضفرد كلمة | الرد`
- `!delrd كلمة` أو `!حذفرد كلمة`
- `!editrd كلمة | الرد الجديد` أو `!تعديلرد كلمة | الرد الجديد`
- `!listrd` أو `!الردود`

## ملاحظة
النسخة تحافظ على منطق الأوامر القديمة وتضيف أوامر الموسيقى. ملفات الإعدادات الحالية لا تُستبدل؛ اترك `data/config.json` الموجود لديك كما هو حتى لا تفقد إعداداتك.

## إضافات YovnBot المدمجة
- `!role`: إنشاء رتبة خاصة عبر أسئلة متتابعة.
- `!myrole`: لوحة مالك الرتبة لإضافة/إزالة أعضاء وتغيير الاسم واللون ونقل الملكية.
- `!تجديد @الرتبة 6 اسبوع`: تجديد الرتبة وإرجاعها لحامليها السابقين.
- انتهاء الرتبة يزيلها من الأعضاء ويحتفظ بسجل الحاملين، دون حذف الرتبة من السيرفر.
- إعلان إنشاء/تجديد الرتبة في روم الإعلان، وسجل الإنشاء فقط في روم السجل.
- تنظيف شات الرومات الصوتية كل 5 دقائق (إن كان نوع الروم يدعم واجهة رسائل Discord).
- أوامر الموسيقى: `ش`، `شغل`، `play`، `وقف`، `stop`، `س`، `سكب`، `skip`، `ص`، `v`.


## الإضافات الجديدة
- روم Locket: `1569338189594886254` فقط؛ يضيف البوت التفاعلات الثلاثة المحددة على الرسائل فيه.
- نشر مقاطع `@serveryovn` في روم `1569339493943873697` عبر RSS، مع حفظ المقاطع المنشورة لمنع التكرار. أول فحص يسجل المقاطع الحالية فقط حتى لا ينشر الأرشيف القديم.
- يمكن تحديد رابط RSS بديل في Render باسم `TIKTOK_RSS_URL` إذا تعطل المصدر الافتراضي.
- لوحة `!myrole` تدعم اختيار الرتبة عند امتلاك أكثر من رتبة، وإضافة/إزالة الأعضاء، وتغيير الاسم واللون والأيقونة، ونقل الملكية.
- أيقونة الرتبة تظهر كصورة مصغرة أكبر في إعلانات الرتبة وسجلها إذا كانت صورة أو إيموجي معروفًا. حجم أيقونة الرتبة داخل قائمة Discord نفسها يحدده Discord ولا يمكن تكبيره من البوت.
- ملفات الحالة الجديدة تُحفظ في `data/tiktokState.json`؛ اترك مجلد `data` الحالي كما هو.


## إضافات Yovn الجديدة

- تفاعلات Locket تعمل فقط في الروم `1569338189594886254` وبالإيموجيات الثلاثة المحددة في الكود.
- فحص مقاطع TikTok لحساب `@serveryovn` ونشر الجديد في `1569339493943873697` مع `@everyone` وعبارة `حطو لايك 😽🤍`، مع حفظ المعرفات المنشورة في `data/tiktokState.json` لمنع التكرار. يمكن تحديد رابط RSS بديل من متغير البيئة `TIKTOK_RSS_URL`.
- إظهار أيقونة الرتبة الخاصة في إعلاناتها وسجل إنشائها، ومحاولة تطبيقها كأيقونة رتبة إذا كان السيرفر يدعم ذلك.
- إصلاح لوحة `!myrole`: اختيار الرتبة، إضافة/إزالة أعضاء، تغيير الاسم واللون والأيقونة، ونقل الملكية، وكل إجراء له مساره الخاص.

**مهم:** استبدل ملف `index.js` فقط في مشروعك الحالي. لا تستبدل مجلد `data` ولا ملف الإعدادات الفعلي ولا أسرار Render. لم يتم اختبار اتصال Discord أو مصدر TikTok مباشرة؛ تم فحص صحة صياغة JavaScript فقط. قد يحتاج نشر TikTok إلى رابط RSS يعمل، ويمكن وضعه في `TIKTOK_RSS_URL`.
