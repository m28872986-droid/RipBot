Yovn Streak Bot
================

المتطلبات:
- Python 3.10 أو أحدث.
- بوت ديسكورد من Discord Developer Portal.
- تفعيل Message Content Intent و Server Members Intent من صفحة Bot في Developer Portal.
- دعوة البوت للسيرفر بصلاحيات View Channels, Send Messages, Embed Links, Add Reactions, Read Message History.

التثبيت:
1) فك ضغط الملف.
2) افتح المجلد في Terminal / CMD.
3) نفّذ:
   python -m pip install -r requirements.txt
4) انسخ .env.example وسمّ النسخة .env
5) افتح .env وضع توكن البوت مكان PUT_YOUR_BOT_TOKEN_HERE.
6) شغّل:
   python bot.py

الإعداد الافتراضي:
- السيرفر: 1564995425331847341
- روم الستريك: 1564997590532096030
- المنطقة الزمنية: Asia/Riyadh
- التذكير: 23:59

الأوامر:
للأعضاء:
- -top

للإدارة (صلاحية Administrator الفعلية):
- -reset @user
- -resetall
- -add @user 10
- -set @user 20
- -remind
- -stats
- -channel #room
- -time 23:59
- -help

طريقة احتساب الستريك:
- فقط الصور المرفقة والستيكرات في روم الستريك المحدد تُحتسب.
- الرسائل النصية العادية يتجاهلها البوت تمامًا.
- أول صورة/ستيكر في اليوم تحتسب؛ أي صورة/ستيكر أخرى في نفس اليوم تحصل على ⚠️.
- عند النجاح يضيف البوت ✅ ويرسل Embed.
- عند التكرار يضيف ⚠️ ويرسل Embed.
- التذكير يُرسل 23:59 بتوقيت السعودية في الخاص والروم.
- الانتهاء يُعالج 00:01 في الخاص والروم.
- البيانات محفوظة في SQLite.

ملاحظات مهمة:
- لا تشارك توكن البوت مع أي شخص. إذا انكشف، أعد توليده فورًا من Developer Portal.
- يجب أن يبقى البرنامج يعمل باستمرار حتى تنفذ التذكيرات المجدولة.
- إذا كان الخاص مغلقًا، يتعذر على البوت إرسال DM لذلك العضو، لكنه يحاول إرسال ملخص الروم.
- هذا مشروع جاهز كبداية ويحتاج اختبارًا في سيرفرك قبل الاعتماد النهائي.
